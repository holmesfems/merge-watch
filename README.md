# merge-watch

Claude Code デスクトップアプリのセッションに bind された GitHub の PR を見張り、**マージされたら、そのセッションを起こして後始末をさせる** mod です。

デスクトップアプリの PR の Auto-fix は、CI の失敗・コンフリクト・レビューのコメントでセッションを起こしますが、マージでは起こしません。merge-watch はその穴をうめます。PR をマージすると、10 秒ほどで Claude が main に切り替えて pull し、マージ済みのブランチを片付けてくれます。

入れておくだけで動きます。コマンドを打つ必要はありません。

## しくみ

- **見張る PR**：そのセッションに bind された PR（アプリの上の PR のバーに出ているもの）。Claude が `gh pr create` で出した PR は、アプリが自動で bind します。
- **見に行く**：10 秒おきに、アプリの `mcp__ccd_pr__get_status` ツールで PR の状態を聞きます。アプリが手元に持っている情報を読むだけなので、GitHub API は使わず、レート制限も気にしなくてよく、トークンも扱いません。
- **マージされたら**：セッションに「PR がマージされたので後始末を」というメッセージを送ります（merge-watch からのメッセージとして届き、ユーザーが打った言葉にはなりません）。セッションがひまならすぐに、作業中ならそのターンが終わってから始まります。同じ PR で二度は頼みません。
- **閉じられたら**：マージされずに閉じた PR は、知らせを 1 行残すだけです。
- 後始末を頼むのは、**開いているのを一度見たことのある PR** がマージされたときだけです。mod を入れる前にマージ済みだった PR のせいで、古いセッションを開いたとたんに動き出すことはありません。開いているのを見た記録はセッションごとに残るので、アプリを閉じているあいだにマージされても、セッションを再開すれば後始末を頼みます。
- デスクトップアプリの外（ターミナルの `claude` など）では、このツールが無いので何もしません。

### 既定の後始末

1. 作業フォルダが PR のリポジトリのものか確かめる（違えばどこでやるか聞く）
2. `git status` を見て、コミットしていない変更があれば止まって聞く
3. マージ先（ふつうは main）に切り替えて `git pull`（ワークツリーの中では切り替えない）
4. マージされたブランチを `git branch -d` で消す（`-D` は使わない）
5. `.claude-plugin/plugin.json` の version が上がっていたら、`claude plugin update <name>` を案内する（自分では動かさない）
6. やったことを短くまとめる

## 入れ方

```
/plugin marketplace add holmesfems/merge-watch
/plugin install merge-watch@merge-watch
```

## 使い方

入れたら、あとは PR を出してマージするだけです。見張っているあいだは、ステータスラインに `merge-watch: #12 を見張り中` と出ます。

`/merge-watch` を打つと、いま見に行って様子を答えます（見張っている PR・マージされたので後始末を頼んだ・見張る PR が無い）。

## 設定

`/config`（または settings の `pluginConfigs.merge-watch`）で変えられます。

| 項目 | 既定 | 意味 |
| --- | --- | --- |
| `intervalSeconds` | 10 | アプリに PR の状態を聞く間隔（秒）。5〜600 |
| `cleanup` | （空） | マージのあとに頼むこと。空なら上の既定の後始末。たとえば「main に切り替えて pull だけして」 |

## 試し方

1. merge-watch を入れて、デスクトップアプリで試しのリポジトリのセッションを開く（入れずに試すなら `claude --plugin-dir <このフォルダ>`。ただしターミナルではアプリのツールが無いので動かない）
2. 適当な変更をブランチに積んで、Claude に「PR を出して」と頼む。PR がセッションに bind されると、ステータスラインに `merge-watch: #N を見張り中` と出る
3. GitHub でその PR をマージする
4. 10 秒ほどで「マージされました」のトーストが出て、Claude が後始末を始める
5. 閉じるだけの PR でも試すと、知らせが 1 行残る

自動テスト：

```
claude plugin validate .
claude plugin test .
```

## ファイル

- `hooks/register.ts`：フック（セッションの開始・`/merge-watch`）と見張りのタイマー
- `hooks/watch.ts`：アプリの答えの読み取り・知らせの文面・いつ頼むかの判断など、`$` を使わない部分
- `tests/merge-watch.test.ts`：テスト
